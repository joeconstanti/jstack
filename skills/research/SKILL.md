# research

Read `.agents/jstack/rules.md` first and apply it.

1. **Define the question.** Identify the decision, audience, boundaries and what
   evidence could change the answer. Use available project context; state a
   reasonable assumption if the question is broad. Do not assume a software
   deliverable. Read `references/evidence.md` beside this file.
2. **Gather evidence.** Start with supplied documents and relevant connected
   sources. Check current primary sources for changing claims. Read the actual
   source, not just a search snippet. For multi-source decisions, record source,
   date/version, locator, supported claim and limitations in a compact ledger.
3. **Compare.** Separate observations from interpretations. Reconcile dates,
   definitions, populations and units before comparing numbers. Seek evidence
   against the leading explanation; duplicated reports are not independent
   confirmation. Explain unresolved conflicts rather than averaging them away.
4. **Synthesize.** Answer the question first. Link material factual claims to
   the supporting passage or file location. Explain competing options, costs,
   uncertainty and the evidence that would reverse the recommendation. Avoid
   precision unsupported by the sources; recommendations are judgments.
5. **Deliver** the requested answer or artifact with sources, assumptions and
   actionable next steps. Fit the depth to the decision. When sources cannot
   settle it, name the missing fact and smallest useful next investigation.
   Save only where requested or required by the project workflow. Private
   source excerpts belong in private destinations, not public repository docs.
